Foundation

Supervised
vs Unsupervised

In supervised learning (Module 4), every training example had a label — "default" or "approved". The model learned to predict that label.

In unsupervised learning, there are no labels. The algorithm must find hidden structure on its own — grouping similar things together, compressing data, or detecting anomalies.

💡
Real-world analogyA school principal groups 500 students by attendance, marks, and behaviour — without any pre-defined category. That's clustering.
When to use Unsupervised
🏷 No Labels Available
You have customer transaction data but no one has manually labelled "loyal" vs "at-risk". Clustering discovers these groups automatically.
🔍 Exploratory Analysis
Before building a supervised model, cluster your data to understand its structure — helps feature engineering.
📉 Too Many Features
200 features → PCA compresses to 10 while keeping 95% of information. Speeds up training dramatically.
🚨 Anomaly Detection
Fraud, defects, network intrusions — rare patterns that don't fit any cluster. DBSCAN labels them as noise.

K-Means

K-Means — How it Works

K-Means partitions N points into K clusters. You must specify K in advance. It works by iteratively assigning each point to the nearest centroid, then moving the centroid to the mean of its cluster.

K-Means in 4 Steps — K=3
Step 1
🎲
Random Init
Place K centroids randomly
Step 2
📍
Assign
Each point → nearest centroid
Step 3
📐
Update
Move centroid to cluster mean
Step 4
🔁
Repeat
Until centroids stop moving
O(nKt)
Time Complexity
Fast
Scales to millions
Euclidean
Distance metric
K-Means Code

3 Lines to Cluster

Sklearn's K-Means is a 3-line fit. The elbow method helps find the right K.

Python
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

km = KMeans(n_clusters=4, random_state=42)
km.fit(X_scaled)
labels = km.labels_       # cluster ID per row
⚠️
Always scale before K-Means Income in ₹ (range 0–100K) will dominate age (range 18–70). StandardScaler brings all features to the same scale.
Elbow Method — Finding K

Run K-Means for K=2 to 10. Plot inertia (within-cluster sum of squares). The "elbow" is where adding more clusters gives diminishing returns.

Python
inertia = []
K_range = range(2, 11)

for k in K_range:
    km = KMeans(n_clusters=k, random_state=42)
    km.fit(X_scaled)
    inertia.append(km.inertia_)

plt.plot(K_range, inertia, "o-", color="#1B9AE4")
plt.xlabel("Number of Clusters K")
plt.ylabel("Inertia (WCSS)")
plt.title("Elbow Method")
plt.show()
# Look for the 'bend' — that's your K
✅
Typical result for Indian e-commerce: Elbow appears at K=4 → Champions, Loyal, At-Risk, Lost customers.
K-Means — Use When

K-Means Scenario Guide

✅ Use K-Means When…
Good Fit
• You know approximately how many clusters to expect
• Clusters are roughly spherical and equal-sized
• Dataset is large (100K+ rows) — K-Means is fast
• Features are numerical and scaled
• Example: Customer segmentation, document grouping, image compression
❌ Avoid K-Means When…
Poor Fit
• Clusters have irregular/non-spherical shapes
• Data has many outliers — outliers distort centroids
• Features are categorical (use K-Modes instead)
• You don't know K at all — use hierarchical instead
• Example: Geographic clusters, anomaly detection
🏦
Indian Industry Usage Paytm uses K-Means to segment 300M users into spending tiers. Swiggy uses it to group delivery zones. HDFC uses it for credit risk banding.
Hierarchical Clustering

Building a
Tree of Clusters

Hierarchical clustering builds a tree (dendrogram) by merging the two most similar points/clusters at each step — no K required.

🌳
Two approaches:
Agglomerative (bottom-up) — start with each point as its own cluster, merge upward. Most common.
Divisive (top-down) — start with one cluster, split downward. Rarely used.
City: A B C D E │ │ │ │ │ Step 1: └─┬─┘ │ │ │ AB C D E Step 2: └──┬──┘ │ │ ABC D E Step 3: └────┬───┘ ABCDE
Code + Linkage Methods
Python
from sklearn.cluster import AgglomerativeClustering
from scipy.cluster.hierarchy import dendrogram, linkage
import matplotlib.pyplot as plt

# Plot dendrogram first — decide K visually
Z = linkage(X_scaled, method="ward")
dendrogram(Z, truncate_mode="lastp", p=12)
plt.title("Dendrogram — Cut line decides K")
plt.show()

# Then fit with chosen K
hc = AgglomerativeClustering(n_clusters=4, linkage="ward")
labels = hc.fit_predict(X_scaled)
✅ Use Hierarchical When…
Good Fit
• You don't know K — dendrogram shows natural K
• Dataset is small to medium (<10K rows) — O(n²) memory
• You need a hierarchy of clusters (country → state → city)
• Example: Gene expression, organisational charts
DBSCAN

Density-Based
Clustering

DBSCAN finds clusters as dense regions separated by sparse regions. It classifies points as core, border, or noise — and noise points are labelled −1.

🔑
Two parameters to set:
eps = radius of neighbourhood
min_samples = minimum points inside that radius to form a core point
✅ Use DBSCAN When…
Good Fit
• Clusters have irregular shapes (geographic, moon-shaped)
• You need automatic outlier detection (noise = −1)
• You don't know K in advance
• Example: Fraud detection, GPS hotspots, anomaly detection
Code
Python
from sklearn.cluster import DBSCAN

db = DBSCAN(
    eps=0.5,           # neighbourhood radius
    min_samples=5      # min points to be 'core'
)
labels = db.fit_predict(X_scaled)

n_clusters = len(set(labels)) - (1 if -1 in labels else 0)
n_noise    = list(labels).count(-1)

print(f"Clusters found : {n_clusters}")
print(f"Noise points   : {n_noise}")
Output Clusters found : 3 Noise points : 47
❌
Avoid DBSCAN when: Clusters have varying densities (DBSCAN uses one eps for all clusters). Use HDBSCAN instead in that case.

Evaluating Clusters

Silhouette Score — Is Your Clustering Good?

Unlike supervised learning, there's no accuracy score. Silhouette measures how well each point fits its own cluster vs neighbouring clusters. Range: −1 (wrong cluster) to +1 (perfect fit). Above 0.5 is good.

Silhouette Formula
s(i) = (b − a) / max(a, b)
a = average distance to all points in same cluster (lower = tighter cluster)
b = average distance to all points in the nearest other cluster (higher = better separation)
Python
from sklearn.metrics import silhouette_score

scores = {}
for k in range(2, 8):
    km  = KMeans(n_clusters=k, random_state=42)
    lbl = km.fit_predict(X_scaled)
    scores[k] = silhouette_score(X_scaled, lbl)

best_k = max(scores, key=scores.get)
print(f"Best K={best_k}  Silhouette={scores[best_k]:.3f}")
OutputBest K=4 Silhouette=0.587

Visualization Tools

t-SNE & UMAP — See Your High-Dimensional Data

PCA is for preprocessing. t-SNE and UMAP are for visualization only — they project data to 2D so you can see clusters visually. Never use them as features for ML models.

🔭 t-SNE
Preserves local structure — similar points stay near each other in 2D. Great for visualising clusters but very slow on large datasets.
Good Fit
Small datasets (<10K), showing cluster separation visually, NLP word embeddings
⚡ UMAP
Preserves both local AND global structure. 10–100× faster than t-SNE. Better for large datasets and can be used as a feature engineering step.
Good Fit
Large datasets, when t-SNE is too slow, preserving global topology
Python

Stacking — Combining Models Smartly

Stacking trains multiple different models (base learners) and uses their predictions as input features to a final meta-learner. Each base model captures different patterns; the meta-learner combines them optimally.

Python
from sklearn.ensemble import StackingClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from xgboost import XGBClassifier

base = [
    ("lr",  LogisticRegression(max_iter=500)),
    ("rf",  RandomForestClassifier(n_estimators=100)),
    ("xgb", XGBClassifier(verbosity=0)),
]
stack = StackingClassifier(
    estimators=base,
    final_estimator=LogisticRegression()
)
stack.fit(X_train, y_train)
print(f"Stack AUC: {roc_auc_score(y_test, stack.predict_proba(X_test)[:,1]):.3f}")
✅
When to Stack: When you've exhausted hyperparameter tuning and need that extra 0.5–2% accuracy. Used heavily in Kaggle competitions and production fintech systems.
Imbalanced Data

SMOTE &
Class Weights

In fraud detection, loan defaults, and disease prediction — the minority class (fraud/default) is rare (1–5%). Models trained on imbalanced data simply predict the majority class always.

Before SMOTE

80% Non-Fraud : 20% Fraud
Non-Fraud 80%
20%
⟹

After SMOTE

50% Non-Fraud : 50% Fraud
Non-Fraud 50%
50%
💡
SMOTE = Synthetic Minority Oversampling Technique. Creates new synthetic samples of the minority class by interpolating between existing minority samples — not simple duplication.
Two Strategies
Strategy 1 — SMOTE (Oversample)
Generates synthetic minority samples before training. Best when minority class has very few examples.
Python
from imblearn.over_sampling import SMOTE

sm = SMOTE(sampling_strategy=0.5, random_state=42)
X_res, y_res = sm.fit_resample(X_train, y_train)
print(y_res.value_counts())
Strategy 2 — Class Weights (Penalise)
Tells the model to penalise mistakes on the minority class more heavily. No new data created — simpler and often effective.
Python
from sklearn.ensemble import RandomForestClassifier

rf = RandomForestClassifier(
    class_weight="balanced",  # auto-computes weights
    random_state=42
)
rf.fit(X_train, y_train)

from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.impute import SimpleImputer
from sklearn.compose import ColumnTransformer
from lightgbm import LGBMClassifier

num_pipe = Pipeline([("imp", SimpleImputer()), ("sc", StandardScaler())])
cat_pipe = Pipeline([("imp", SimpleImputer(strategy="most_frequent")),
                     ("enc", OneHotEncoder(handle_unknown="ignore"))])

preprocess = ColumnTransformer([
    ("num", num_pipe, num_cols),
    ("cat", cat_pipe, cat_cols),
])
full_pipe = Pipeline([("prep", preprocess), ("model", LGBMClassifier())])

full_pipe.fit(X_train, y_train)
preds = full_pipe.predict(X_test)  # preprocessing auto-applied!
✅
Always use Pipelines in production. Pass the raw DataFrame to full_pipe.predict() — no manual preprocessing needed. This eliminates an entire class of deployment bugs.

Lab Step 2

RFM Analysis — Quantify Customer Value

RFM is the industry-standard framework for customer segmentation in e-commerce. It converts raw transaction data into three scores that together describe customer value.

📅

Recency

How many days ago did they last order?
Lower is better — recent buyers are more engaged

🔁

Frequency

How many orders did they place?
Higher is better — repeat buyers have lower churn risk

💰

Monetary

How much total have they spent (₹)?
Higher is better — high spenders = high LTV

Python
import pandas as pd
from datetime import datetime

df = pd.read_csv("ecommerce_india.csv", parse_dates=["InvoiceDate"])
snapshot = df["InvoiceDate"].max() + pd.Timedelta(days=1)  # reference date

rfm = df.groupby("CustomerID").agg(
    Recency   = ("InvoiceDate", lambda x: (snapshot - x.max()).days),
    Frequency = ("InvoiceNo",   "nunique"),
    Monetary  = ("TotalAmount", "sum")
).reset_index()

print(rfm.describe().round(1))

K-Means on
RFM Scores

Scale the RFM scores (Monetary has a much larger range), find optimal K, and fit K-Means. Add the cluster label back to the DataFrame.

from sklearn.preprocessing import StandardScaler

from sklearn.metrics import silhouette_score

# Log-transform Monetary (right-skewed)
rfm["M_log"] = np.log1p(rfm["Monetary"])
features = ["Recency","Frequency","M_log"]

# Silhouette to pick K

Review — Question 1 of 3

Quick Quiz

A Nykaa data scientist wants to group 2 million products by colour, texture, and price — clusters have irregular shapes and some products don't fit any group (outliers). Which algorithm should they use?
AK-Means — fast and scales to millions
BHierarchical — good for any cluster shape
CDBSCAN — handles irregular shapes AND labels outliers as noise (-1)
DPCA — reduces the feature space before clustering
💡
Key reasoning: Irregular shapes → rules out K-Means. Outlier handling needed → DBSCAN. Scale (2M products) would also be fine for DBSCAN with a spatial index.
Review — Question 2 of 3

Quick Quiz

Your loan default model has 98% accuracy but only 8% recall on the "default" class (only 2% of customers default). What is the correct fix?
ACollect more data — 8% recall means the dataset is too small
BUse PCA — reduce features to improve recall
CApply SMOTE or class_weight="balanced" — severe class imbalance is causing the model to predict "no default" for everyone
DIncrease max_depth — the model is underfitting
⚠️
Classic trap: 98% accuracy on 2% minority class means predicting majority always → accuracy = 98%. Recall = 8% confirms the model is missing 92% of defaulters. Fix = rebalancing, not more data or complexity.
Review — Question 3 of 3

Quick Quiz

A team runs K-Means with K=3, 4, 5 and gets Silhouette scores of 0.31, 0.62, 0.58. They choose K=4. A colleague suggests adding more clusters until Silhouette reaches 0.9. What is wrong with this suggestion?
ASilhouette score can never exceed 0.7 — 0.9 is mathematically impossible
BMore clusters always reduce Silhouette — K=4 is always optimal
COver-clustering creates meaningless segments. K=4 gave the natural elbow — adding more clusters splits real groups and loses business interpretability
DK-Means cannot have more than 5 clusters on real data
✅
Business rule: If you split "Loyal Customers" into sub-clusters, marketing cannot act on the distinction. K=4 with interpretable segments is better than K=8 with a 0.73 Silhouette score.
Module Summary

Everything You Learned in Module 5

🎯 K-Means
Partitions into K spherical clusters. Fast, scalable. Needs scaling + known K. Use: customer segmentation, document grouping.
🌳 Hierarchical
Builds dendrogram bottom-up. No K needed. Slow on large data. Use: gene analysis, small datasets, unknown K.
🔵 DBSCAN
Density-based. Finds arbitrary shapes. Automatic outlier detection. Use: fraud, geographic clusters, anomaly detection.
📉 PCA
Compresses features while retaining 95% variance. Use: too many features, speed up training, remove multicollinearity.
👁 t-SNE / UMAP
2D visualization only (t-SNE) or fast projection (UMAP). Never use as ML features. Use: visualising cluster quality.
⚖️ SMOTE + Weights
Fix class imbalance. SMOTE = synthesise new minority samples. class_weight = penalise majority errors. Use: fraud, churn, disease.
