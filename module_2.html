7.1 Understanding HTML — The Target

What Web Scrapers Read

Before scraping, you must understand HTML structure. Every webpage is a tree of nested tags. You navigate this tree to find the data you want. Here is a simplified job card from a Naukri-style board:

Read this HTML carefully. A real job listing page repeats this structure hundreds of times — once per job. Your scraper's job is to extract the text inside each tag automatically.
HTML (Target Page)
<div class="job-card">
  <h2 class="job-title">Data Scientist</h2>
  <p  class="company">Infosys</p>
  <span class="location">Bengaluru, Karnataka</span>
  <span class="salary">₹12 – 18 LPA</span>
  <ul class="skills">
    <li>Python</li>
    <li>SQL</li>
    <li>Machine Learning</li>
  </ul>
</div>
🔍
How to inspect any website Right-click any element on a webpage → "Inspect Element" (Chrome/Firefox). The DevTools panel shows the exact HTML structure. Find the repeating container — that is what you iterate over.

The Three Ways to Find Elements

Know these three methods. Together they cover 99% of all scraping tasks. Use find() for one element, find_all() for many, and select() for CSS selectors (most powerful).
Python
# find() — returns FIRST match (or None if not found)
title = soup.find("h2", class_="job-title")
print(title.text.strip())          # "Data Scientist"

# find_all() — returns LIST of ALL matches
all_cards = soup.find_all("div", class_="job-card")
print(f"Found {len(all_cards)} jobs")   # Found 48 jobs

# select() — CSS selector syntax (most flexible)
titles    = soup.select("div.job-card h2.job-title")
locations = soup.select("div.job-card span.location")

Extracting Text, Attributes & Nested Data

Three accessors: .text or .get_text() for visible text, ["attr"] or .get("attr") for HTML attributes like href and src.
Python
card = soup.find("div", class_="job-card")

# Text extraction
title    = card.find("h2").get_text(strip=True)   # "Data Scientist"
company  = card.find("p",    class_="company").text.strip()

# Attribute extraction (links, image URLs)
link_tag = card.find("a")
url      = link_tag.get("href", "")               # safe — returns "" if missing

# Nested list — skills
skill_tags = card.select("ul.skills li")
skills     = [li.get_text(strip=True) for li in skill_tags]
# ['Python', 'SQL', 'Machine Learning']
7.3 Project Step 1 — Scraping Indian Tech Jobs

Full Job Board Scraper

We now build the first piece of our project — a scraper that loops through multiple pages of a job board and collects all listings into a Pandas DataFrame.

⚠️
Always add a User-Agent header Many websites block requests that look like bots (no browser headers). A simple User-Agent header mimics a browser and prevents most blocks.
Pattern: Outer loop = pages, Inner loop = job cards per page. Clean each field immediately before storing it.
Python
import requests, time, pandas as pd
from bs4 import BeautifulSoup

HEADERS = {"User-Agent": "Mozilla/5.0 (compatible; DataScienceBot/1.0)"}
BASE_URL = "https://example-job-board.in/data-science?page={}"

def scrape_page(page_num):
    """Scrape one page, return list of job dicts."""
    url      = BASE_URL.format(page_num)
    response = requests.get(url, headers=HEADERS, timeout=10)
    soup     = BeautifulSoup(response.text, "lxml")
    jobs     = []

    for card in soup.find_all("div", class_="job-card"):
        jobs.append({
            "title"   : card.find("h2").get_text(strip=True),
            "company" : card.find("p", class_="company").get_text(strip=True),
            "city"    : card.find("span", class_="location").get_text(strip=True),
            "salary"  : card.find("span", class_="salary").get_text(strip=True),
            "skills"  : ", ".join(li.text for li in card.select("ul.skills li")),
            "url"     : card.find("a").get("href", ""),
        })
    return jobs

# ── Scrape 5 pages ───────────────────────────────
all_jobs = []
for page in range(1, 6):
    all_jobs.extend(scrape_page(page))
    time.sleep(1.5)          # pause between requests — polite scraping
    print(f"Page {page} done — {len(all_jobs)} jobs so far")

df = pd.DataFrame(all_jobs)
print(df.shape)              # (240, 6) — 240 jobs, 6 columns

Cleaning the Scraped Data

Raw scraped data is always messy. Salary is a string like "₹12 – 18 LPA". Extract the numeric range before storing.
Python
import re

def parse_salary(salary_str):
    """'₹12 – 18 LPA' → min=12, max=18, avg=15."""
    nums = re.findall(r"\d+\.?\d*", salary_str)
    if len(nums) >= 2:
        lo, hi = float(nums[0]), float(nums[1])
        return lo, hi, round((lo + hi) / 2, 1)
    return None, None, None

df[["sal_min","sal_max","sal_avg"]] = df["salary"].apply(
    lambda s: pd.Series(parse_salary(s))
)
df["city"] = df["city"].str.split(",").str[0].str.strip()

print(df[["title","company","city","sal_avg"]].head(3))

7.4 REST APIs — Fetching Live Data

Project Step 2 — Fetch City Cost-of-Living via API

Salary means nothing without context. ₹12 LPA in Mumbai feels like ₹8 LPA — but ₹12 LPA in Jaipur is comfortable. We enrich our job data with city cost-of-living indices from a public API.

API response is JSON. Parse it directly into a Python dict, then into a DataFrame using pd.json_normalize() for nested structures.
Python
import requests, pandas as pd

def fetch_city_data(city):
    """Fetch cost-of-living index for an Indian city."""
    url      = f"https://api.costoflivingindex.in/v1/city/{city}"
    response = requests.get(url, timeout=8)
    if response.status_code != 200:
        return {}
    return response.json()   # e.g. {"city":"Mumbai","index":78.4,"rent_idx":92.1}

# Build a lookup table for the cities in our dataset
cities      = df["city"].unique()          # ['Bengaluru','Mumbai','Hyderabad',...]
city_records = [fetch_city_data(c) for c in cities]

city_df = pd.DataFrame(city_records)[["city", "index", "rent_idx"]]
city_df.rename(columns={"index":"col_index"}, inplace=True)

Enriching the Jobs Data

Merge the two DataFrames on the city column, then compute a real-value salary — salary adjusted for cost of living — so salaries across cities become comparable.
Python
# Left join — keep all jobs, add city COL index
df = pd.merge(df, city_df, on="city", how="left")

# Real-value salary: higher COL city → effectively lower purchasing power
df["sal_real"] = (df["sal_avg"] / df["col_index"] * 100).round(2)

print(df[["city","sal_avg","col_index","sal_real"]].head(4))

7.5 Authentication & Rate Limiting

API Keys & Polite Requests

🔑

API Key Auth

Most data APIs (RapidAPI, data.gov.in, etc.) require a key sent in the request header.

⏱

Rate Limits

APIs restrict how many calls you can make per minute. Violating this gets your key blocked.

🔁

Retry Logic

Networks fail. Always wrap API calls in try-except with automatic retries and exponential backoff.

😴

Polite Scraping

Add time.sleep(1) between requests. It prevents server overload and reduces your block risk.

Production-grade API caller — handles auth, rate limits, retries, and exponential backoff in one reusable function.
Python
import requests, time, os

API_KEY = os.getenv("DATA_GOV_IN_KEY")  # store secrets in env vars, never hardcode

def api_call(endpoint, params=None, retries=3):
    headers = {
        "api-key"    : API_KEY,
        "User-Agent" : "IndiaJobAnalyser/1.0",
    }
    for attempt in range(retries):
        try:
            r = requests.get(endpoint, headers=headers,
                             params=params, timeout=10)
            r.raise_for_status()         # raises on 4xx / 5xx
            return r.json()
        except requests.exceptions.HTTPError as e:
            if r.status_code == 429:     # 429 = Too Many Requests
                wait = 2 ** attempt      # exponential backoff: 1s, 2s, 4s
                print(f"Rate limited. Waiting {wait}s...")
                time.sleep(wait)
            else:
                print(f"HTTP Error: {e}")
                return None
        except requests.exceptions.Timeout:
            print(f"Timeout on attempt {attempt+1}")
    return None

8.1 SQLite — Your Pocket Database

Why SQLite for Data Science?

SQLite is a self-contained database stored in a single file. No server to configure, no passwords to set — perfect for local projects, ETL pipelines, and prototyping. Python's sqlite3 module ships built-in.

✅
SQLite vs PostgreSQL — when to use which Use SQLite for local projects, pipelines, scripts, or datasets under ~1GB. Use PostgreSQL when you need multi-user access, very large datasets, or advanced features like full-text search and JSON columns.
Four steps every time: Connect → Create table → Insert data → Query.
Python
import sqlite3, pandas as pd

# Connect — creates the file if it doesn't exist
conn = sqlite3.connect("india_jobs.db")
cur  = conn.cursor()

# Create table — define schema
cur.execute("""
    CREATE TABLE IF NOT EXISTS jobs (
        id        INTEGER PRIMARY KEY AUTOINCREMENT,
        title     TEXT    NOT NULL,
        company   TEXT,
        city      TEXT,
        sal_avg   REAL,
        sal_real  REAL,
        skills    TEXT,
        scraped_at TEXT  DEFAULT (date('now'))
    )
""")
conn.commit()

Loading the Scraped DataFrame into SQLite

Pandas to_sql() writes an entire DataFrame to a table in one line — no manual INSERT loops needed.
Python

CRUD — Create, Read, Update, Delete

Always use parameterised queries (the ? placeholder). Never format user input directly into a SQL string — that opens SQL injection vulnerabilities.
Python
# INSERT a single record — parameterised (safe ✓)
cur.execute("""
    INSERT INTO jobs (title, company, city, sal_avg, skills)
    VALUES (?, ?, ?, ?, ?)
""", ("Data Analyst", "HDFC Bank", "Mumbai", 9.5, "SQL, Excel, Power BI"))
conn.commit()

# UPDATE
cur.execute("UPDATE jobs SET sal_avg = ? WHERE id = ?", (10.0, 241))
conn.commit()

# DELETE
cur.execute("DELETE FROM jobs WHERE sal_avg IS NULL")
conn.commit()

Aggregate Functions — GROUP BY

GROUP BY collapses rows with the same value into one row, then applies an aggregate function (COUNT, AVG, SUM, MAX, MIN) to each group.
SQL + Python
q = """
    SELECT   city,
             COUNT(*)          AS total_jobs,
             ROUND(AVG(sal_avg), 1) AS avg_salary_lpa,
             ROUND(MAX(sal_avg), 1) AS max_salary_lpa
    FROM     jobs
    GROUP BY city
    HAVING   COUNT(*) >= 10          -- only cities with 10+ listings
    ORDER BY avg_salary_lpa DESC
"""
city_stats = pd.read_sql(q, conn)
print(city_stats)
Output city total_jobs avg_salary_lpa max_salary_lpa 0 Bengaluru 88 16.2 32.0 1 Hyderabad 52 14.8 26.0 2 Gurugram 41 14.1 28.5 3 Mumbai 39 13.2 24.0 4 Pune 22 12.6 20.0 5 Chennai 18 12.1 18.5

Filtering on Aggregates — HAVING vs WHERE

🧠

Key rule: WHERE filters rows before grouping. HAVING filters groups after aggregation. You cannot use aggregate functions inside a WHERE clause.

SQL + Python
q = """
    SELECT   LOWER(title)      AS role,
             COUNT(*)          AS listings,
             ROUND(AVG(sal_avg), 1) AS avg_lpa
    FROM     jobs
    WHERE    scraped_at >= date('now', '-30 days')  -- last 30 days
    GROUP BY LOWER(title)
    HAVING   COUNT(*) >= 5
    ORDER BY listings DESC
    LIMIT 8
"""
print(pd.read_sql(q, conn))

INNER JOIN, LEFT JOIN — Side by Side

JOIN TypeReturnsWhen to Use
INNER JOINOnly rows that match in BOTH tablesWhen you need complete records only
LEFT JOINAll rows from left table + matching from right (NULL if no match)When you want all jobs, even if city data is missing
LEFT JOIN + IS NULLOnly rows in left table NOT in right tableFinding orphan records
Real query: Combine jobs + companies + cities to get a rich insight — best sectors to apply in, broken down by city tier.
SQL + Python
q = """
    SELECT j.title,
           j.company,
           c.sector,
           j.city,
           ct.state,
           ct.tier,
           j.sal_avg,
           ct.col_index,
           ROUND(j.sal_avg / ct.col_index * 100, 1) AS sal_real

8.4 ETL Pipeline — Extract, Transform, Load

What is ETL?

Extract data from sources (web, API, CSV). Transform it (clean, enrich, reshape). Load it into a destination (database, data warehouse). This is the backbone of all data engineering.

E

Extract

Scraper + API calls. Pull raw data from multiple sources.

T

Transform

Clean, merge, derive new columns. Apply business logic.

L

Load

Write clean data to SQLite (or PostgreSQL in production).

Q

Query

SQL analytical queries for insights and dashboards.

Wrap the full pipeline in one function so it can be scheduled to run daily (e.g., via a cron job or GitHub Actions) and always keep the database fresh.
Python
import sqlite3, pandas as pd, logging
from datetime import datetime

logging.basicConfig(level=logging.INFO, format="%(asctime)s — %(message)s")

def run_etl(pages=5):
    """Full ETL pipeline: scrape → enrich → clean → load → query."""
    start = datetime.now()
    logging.info("ETL started")

    # EXTRACT
    raw_jobs = []
    for p in range(1, pages + 1):
        raw_jobs.extend(scrape_page(p))    # our function from Session 7
    logging.info(f"Extracted {len(raw_jobs)} raw jobs")

    # TRANSFORM
    df = pd.DataFrame(raw_jobs)
    df = clean_jobs(df)                    # type fixes, salary parsing
    df = enrich_with_city_api(df)          # COL index merge
    df["etl_run"] = start.strftime("%Y-%m-%d %H:%M")
    logging.info(f"Transformed → {df.shape[0]} clean rows")

    # LOAD
    conn = sqlite3.connect("india_jobs.db")
    # Remove today's previous run to avoid duplicates
    conn.execute("DELETE FROM jobs WHERE etl_run LIKE ?",
                 (start.strftime("%Y-%m-%d") + "%",))
    df.to_sql("jobs", conn, if_exists="append", index=False)
    conn.commit()
    logging.info("Loaded into SQLite ✓")

    # QUICK SANITY CHECK
    total = pd.read_sql("SELECT COUNT(*) FROM jobs", conn).iloc[0,0]
    logging.info(f"Total records in DB: {total}")
    conn.close()
    logging.info(f"ETL finished in {(datetime.now()-start).seconds}s")

run_etl(pages=5)

Part A — Full Pipeline

This is the complete, runnable pipeline. It calls the helper functions built across both sessions. In an exam/lab, you are expected to write the helper functions (scrape_page, clean_jobs, enrich_with_city_api) yourself.
Python — india_jobs_pipeline.py
"""
India Tech Job Market Analyser
Module 2 — End-to-End Project
"""
import sqlite3, requests, time, re, logging
import pandas as pd
from bs4 import BeautifulSoup
from datetime import datetime

# ── CONFIG ────────────────────────────────────────
DB_PATH  = "india_jobs.db"
BASE_URL = "https://example-job-board.in/data-science?page={}"
HEADERS  = {"User-Agent": "Mozilla/5.0 (IndiaJobAnalyser/1.0)"}

logging.basicConfig(level=logging.INFO, format="%(asctime)s %(message)s")

# ── EXTRACT ───────────────────────────────────────
def scrape_all(pages=5):
    jobs = []
    for p in range(1, pages + 1):
        try:
            r    = requests.get(BASE_URL.format(p), headers=HEADERS, timeout=10)
            soup = BeautifulSoup(r.text, "lxml")
            for card in soup.find_all("div", class_="job-card"):
                jobs.append({
                    "title"  : card.find("h2").get_text(strip=True),
                    "company": card.find("p", class_="company").get_text(strip=True),
                    "city"   : card.find("span", class_="location")
                                   .get_text(strip=True).split(",")[0].strip(),
                    "salary" : card.find("span", class_="salary").get_text(strip=True),
                    "skills" : ", ".join(li.text for li in card.select("ul.skills li")),
                })
        except Exception as e:
            logging.warning(f"Page {p} failed: {e}")
        time.sleep(1.2)
    return pd.DataFrame(jobs)

# ── TRANSFORM ─────────────────────────────────────
def transform(df):
    # Parse salary
    def parse_sal(s):
        nums = re.findall(r"\d+\.?\d*", str(s))
        return (float(nums[0]), float(nums[1])) if len(nums) >= 2 else (None, None)

    df[["sal_min","sal_max"]] = df["salary"].apply(lambda s: pd.Series(parse_sal(s)))
    df["sal_avg"] = ((df["sal_min"] + df["sal_max"]) / 2).round(1)
    df.drop(columns=["salary"], inplace=True)
    df.drop_duplicates(subset=["title","company","city"], inplace=True)
    df.dropna(subset=["sal_avg"], inplace=True)
    df["scraped_at"] = datetime.now().strftime("%Y-%m-%d")
    return df

# ── ENRICH ────────────────────────────────────────
COL_INDEX = {                  # cost-of-living index — mock values
    "Bengaluru":71.2, "Hyderabad":65.8, "Mumbai":78.4,
    "Gurugram":74.1,  "Pune":62.5,      "Chennai":63.1,
    "Delhi":77.0,     "Noida":72.5,     "Kolkata":58.0,
}
def enrich(df):
    df["col_index"] = df["city"].map(COL_INDEX)
    df["sal_real"]  = (df["sal_avg"] / df["col_index"] * 100).round(1)
    return df

# ── LOAD ──────────────────────────────────────────
def load(df):
    conn = sqlite3.connect(DB_PATH)
    conn.execute("DELETE FROM jobs WHERE scraped_at = ?",
                 (datetime.now().strftime("%Y-%m-%d"),))
    df.to_sql("jobs", conn, if_exists="append", index=False)
    conn.commit()
    return conn

# ── RUN ───────────────────────────────────────────
logging.info("Pipeline starting...")
raw_df   = scrape_all(pages=5);   logging.info(f"Scraped: {len(raw_df)} rows")
clean_df = transform(raw_df);     logging.info(f"Clean:   {len(clean_df)} rows")
rich_df  = enrich(clean_df);      logging.info(f"Enriched with COL index")
conn     = load(rich_df);         logging.info("Loaded to SQLite ✓")

def run_insights(conn):
    qs = {

    # Q1: Which city has the best real-value salary for data scientists?
    "Best city (adjusted salary)": """
        SELECT city, ROUND(AVG(sal_real),1) AS avg_real_lpa, COUNT(*) AS jobs
        FROM   jobs
        GROUP  BY city HAVING COUNT(*) >= 8
        ORDER  BY avg_real_lpa DESC LIMIT 5
    """,

    # Q2: Which skills appear most in high-paying jobs (>15 LPA)?
    "Top skills in high-pay jobs": """
        SELECT skills, COUNT(*) AS jobs, ROUND(AVG(sal_avg),1) AS avg_lpa
        FROM   jobs  WHERE sal_avg > 15
        GROUP  BY skills HAVING COUNT(*) >= 3
        ORDER  BY jobs DESC LIMIT 8
    """,

    # Q3: Which companies pay the most on average?
    "Top paying companies": """
        SELECT company, COUNT(*) AS openings, ROUND(AVG(sal_avg),1) AS avg_lpa
        FROM   jobs
        GROUP  BY company HAVING COUNT(*) >= 3
        ORDER  BY avg_lpa DESC LIMIT 10
    """,

    # Q4: Salary gap between Tier-1 and Tier-2 cities?
    "Tier-1 vs Tier-2 salary": """
        SELECT CASE WHEN city IN ('Bengaluru','Mumbai','Hyderabad','Delhi','Chennai','Kolkata')
                    THEN 'Tier-1' ELSE 'Tier-2' END AS tier,
               COUNT(*) AS jobs, ROUND(AVG(sal_avg),1) AS avg_lpa
        FROM   jobs GROUP BY tier
    """,

    # Q5: Month-over-month trend in new listings
    "Weekly hiring trend": """
        SELECT scraped_at AS date, COUNT(*) AS new_listings, ROUND(AVG(sal_avg),1) AS avg_lpa
        FROM   jobs
        GROUP  BY scraped_at ORDER BY scraped_at
    """,
    }

    results = {}
    for name, query in qs.items():
        df = pd.read_sql(query, conn)
        print(f"\n{'═'*50}")
        print(f"  {name}")
        print(f"{'═'*50}")
        print(df.to_string(index=False))
        results[name] = df
    return results

insights = run_insights(conn)
