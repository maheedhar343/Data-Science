9.1 Load & First Look

Getting the Zomato Data

Download zomato.csv from the Kaggle link in the sidebar. Every EDA starts with the same ritual: load → inspect → understand the shape of the data.

Why do we inspect before we plot? Plotting wrong data types or ignoring 40% missing values produces beautiful but misleading charts. Understand structure first, visualise second.
📌 Used at: every single real-world DS project kickoff.
Python
import pandas as pd
import numpy as np
import warnings
warnings.filterwarnings("ignore")

df = pd.read_csv("zomato.csv", encoding="latin-1")

print(df.shape)          # (51717, 17)
print(df.columns.tolist())
# ['url','address','name','online_order','book_table','rate',
#  'votes','phone','location','rest_type','dish_liked',
#  'cuisines','approx_cost(for two people)','reviews_list',
#  'menu_item','listed_in(type)','listed_in(city)']

df.info()                # see dtypes + non-null counts
Output — df.info() (key columns) # Column Non-Null Count Dtype --- ------ -------------- ----- 0 name 51717 non-null object 4 online_order 51717 non-null object 5 rate 43942 non-null object ← stored as "4.1/5" 6 votes 51717 non-null int64 11 approx_cost(for two people) 51371 non-null object ← "300" or "1,200"

Cleaning for EDA

Raw Zomato data has two tricky columns. rate is a string like "4.1/5" and approx_cost contains commas. Fix both before any analysis.
Python
df.rename(columns={
    "approx_cost(for two people)": "cost",
    "listed_in(type)":             "meal_type",
    "listed_in(city)":             "area",
}, inplace=True)

# "4.1/5" → 4.1  |  "NEW" or "-" → NaN
df["rate"] = df["rate"].replace(["NEW", "-"], np.nan)
df["rate"] = df["rate"].str.extract(r"(\d+\.\d+)").astype(float)

# "1,200" → 1200
df["cost"] = df["cost"].str.replace(",", "").astype(float)

# Binary → boolean
df["online_order"] = df["online_order"].map({"Yes": True, "No": False})
df["book_table"]   = df["book_table"].map({"Yes": True, "No": False})

print(df[["name","rate","cost","votes"]].head(3))

10.1 Histogram + KDE — Distribution of a Single Variable

When & Why

📊

Histogram

Divides the range into equal-width bins and counts how many values fall in each bin. Shows frequency distribution.

Use for: any continuous variable
〰️

KDE (Kernel Density)

A smooth curve estimating the probability density. Overlaying it on a histogram reveals the true shape without bin-size bias.

Use for: comparing two groups
Expected Output — Rating Distribution + KDE
Ratings peak at 4.1 (left-skewed tail near 2.0). Median > Mean confirms left skew. Very few restaurants below 3.0 — Zomato may delist consistently poor ones.
Code recipe: sns.histplot() with kde=True draws both in one call. Always add a vertical line for mean and median so readers can see central tendency instantly.
Python
fig, axes = plt.subplots(1, 2, figsize=(12, 4))

# Left: Rating distribution
sns.histplot(df["rate"].dropna(), bins=30, kde=True,
             color=COLORS[0], ax=axes[0])
axes[0].axvline(df["rate"].mean(),   color="red",    linestyle="--", label="Mean")
axes[0].axvline(df["rate"].median(), color="orange", linestyle="-.", label="Median")
axes[0].set(title="Restaurant Ratings — Bengaluru", xlabel="Rating (out of 5)")
axes[0].legend()

# Right: Cost (log scale — right-skewed data)
sns.histplot(df["cost"].dropna(), bins=40, kde=True,
             color=COLORS[1], ax=axes[1], log_scale=(True, False))
axes[1].set(title="Cost for Two (log scale)", xlabel="₹ Cost")

plt.tight_layout()
plt.savefig("rating_cost_dist.png", dpi=150, bbox_inches="tight")
plt.show()
⚠️
Log scale for skewed data — Cost is right-skewed (most restaurants: ₹200–₹800, outliers up to ₹6000). On a linear axis the outliers compress everything left. Use log_scale=True to spread the distribution and make patterns visible.
10.2 Box Plot + Violin Plot — Spread & Outliers

When & Why

📦

Box Plot

Shows Q1, median, Q3, whiskers (1.5×IQR), and individual outliers. Perfect for comparing spread across categories.

Use for: outlier detection, category comparison
🎻

Violin Plot

Box plot + KDE mirrored on both sides. Reveals bimodal or irregular distributions that a box plot hides.

Use for: distribution shape matters
Expected Output — Cost by Meal Type (Box)
Delivery
Dine-out
Cafes
Pubs
Pubs & bars show highest cost + widest spread. Delivery skews lower. Multiple outliers visible above whiskers — premium restaurants in each category.
Key parameter: order= sorts categories by median so patterns read left-to-right. Always sort your categorical axis — random ordering hides trends.
Python
top_types = df["meal_type"].value_counts().head(6).index
plot_df   = df[df["meal_type"].isin(top_types)]

fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# Box plot — sorted by median cost
order = plot_df.groupby("meal_type")["cost"].median().sort_values().index
sns.boxplot(data=plot_df, x="meal_type", y="cost",
            order=order, palette="Set2", ax=axes[0],
            showfliers=False)        # hide outliers for cleaner read
axes[0].set(title="Cost by Meal Type (IQR)", xlabel="", ylabel="₹ Cost for Two")
axes[0].tick_params(axis="x", rotation=30)

# Violin — shows bimodal distribution in some types
sns.violinplot(data=plot_df, x="meal_type", y="rate",
               order=order, palette="Set2", ax=axes[1],
               inner="quartile")    # quartile lines inside violin
axes[1].set(title="Rating Distribution by Type", xlabel="", ylabel="Rating")
axes[1].tick_params(axis="x", rotation=30)

plt.tight_layout()
plt.show()

10.4 Scatter + Bubble Chart — Relationships

When & Why

Scatter plots reveal the relationship between two continuous variables. A bubble chart adds a third dimension using point size.

Expected Output — Cost vs Rating (colour = online order)
Positive correlation (r=0.34): higher cost → slightly higher rating. Green (online order = Yes) clusters towards upper right — premium restaurants offer both.
Scatter plot tip: With 51K points you get overplotting (all dots on top of each other). Fix it with alpha=0.1 (transparency) or sample 5,000 rows. Overplotted charts look like solid blobs and hide patterns.
Python
sample = df.dropna(subset=["rate","cost"]).sample(4000, random_state=42)

fig, axes = plt.subplots(1, 2, figsize=(13, 5))

# Scatter with colour encoding
sns.scatterplot(data=sample, x="cost", y="rate",
                hue="online_order", alpha=0.4, s=20,
                palette={True:"#66bb6a", False:"#ef5350"},
                ax=axes[0])
axes[0].set(title="Cost vs Rating\n(colour = online order)",
            xlabel="₹ Cost for Two", ylabel="Rating")
axes[0].set_xlim(0, 3000)   # cap x-axis — extreme outliers distort

# Bubble chart — location-level summary
loc = df.groupby("location").agg(
    avg_rating=("rate","mean"), avg_cost=("cost","mean"),
    count=("name","count")).dropna().reset_index()
loc = loc[loc["count"] >= 50]   # only well-sampled locations

scatter = axes[1].scatter(loc["avg_cost"], loc["avg_rating"],
                          s=loc["count"]/5, alpha=0.6,
                          c=loc["avg_cost"], cmap="YlOrRd")
for _, row in loc.nlargest(5,"count").iterrows():
    axes[1].annotate(row["location"],
                     (row["avg_cost"], row["avg_rating"]),
                     fontsize=7, ha="center")
axes[1].set(title="Avg Cost vs Rating per Location\n(bubble = no. of restaurants)",
            xlabel="₹ Avg Cost", ylabel="Avg Rating")

plt.tight_layout()
plt.show()

Votes correlates most strongly with rating (0.52) — popular restaurants tend to be better rated. Cost-rating correlation (0.34) suggests higher-end restaurants are slightly better but the relationship is weak.
Always mask the upper triangle — it is a mirror of the lower and adds clutter. Use annot=True to print correlation values inside cells. Pick a diverging colourmap (RdBu, coolwarm) centred at 0, not a sequential one.
Python
num_cols = ["rate", "cost", "votes"]
corr     = df[num_cols].corr()

# Mask upper triangle (redundant mirror)
mask = np.triu(np.ones_like(corr, dtype=bool))

plt.figure(figsize=(6, 5))
sns.heatmap(corr, mask=mask, annot=True, fmt=".2f",
            cmap="RdYlGn", vmin=-1, vmax=1,
            linewidths=0.5, square=True,
            cbar_kws={"shrink": 0.7})
plt.title("Correlation Matrix — Zomato Bengaluru", pad=14)
plt.tight_layout()
plt.show()
10.6 Pair Plot — Every Relationship at Once

When & Why

A pair plot (scatter matrix) shows scatter plots for every numeric pair and histograms/KDEs on the diagonal. It is the most comprehensive single call in exploratory analysis.

⚠️
Use on samples, not full data. A pair plot on 51K rows will take 5+ minutes to render. Always sample 2,000–3,000 rows first. Also limit to 4–5 columns max — beyond that it becomes unreadable.
Python
sample = df[["rate","cost","votes","online_order"]].dropna().sample(2500, random_state=0)
sample["online_order"] = sample["online_order"].map({True:"Online",False:"No Online"})

g = sns.pairplot(sample, hue="online_order",
                 palette={"Online":"#66bb6a","No Online":"#ef5350"},
                 plot_kws={"alpha":0.3, "s":10},
                 diag_kind="kde")         # KDE on diagonal
g.fig.suptitle("Pair Plot — Zomato Numeric Columns", y=1.02)
plt.show()
# Insight: online_order=Yes clusters at higher ratings in all panels
10.7 FacetGrid — Small Multiples

When & Why

FacetGrid creates a grid of the same plot for different subgroups. It is the most powerful technique for comparing patterns across multiple categories simultaneously.

Rule of thumb: If you find yourself copy-pasting a plot and changing one variable, use FacetGrid instead. It ensures consistent axes and layout automatically.
Python
top_areas = df["meal_type"].value_counts().head(4).index
sub       = df[df["meal_type"].isin(top_areas)].dropna(subset=["rate","cost"])

g = sns.FacetGrid(sub, col="meal_type", col_wrap=2,
                  height=4, sharey=True, sharex=True)
g.map(sns.histplot, "rate", bins=20, kde=True, color="#ea580c", alpha=0.7)
g.set_axis_labels("Rating", "Count")
g.set_titles("{col_name}")
g.fig.suptitle("Rating Distribution by Meal Type", y=1.02)
plt.show()
# Delivery restaurants have a wider, flatter distribution
# Dine-out peaks sharply at 4.2 — premium filter effect

11.1 Plotly Express — Interactive Charts in One Line

Why Plotly?

Seaborn makes publication-quality static images. Plotly makes interactive charts — hover tooltips, zoom, click-to-filter — perfect for stakeholder dashboards. Plotly Express wraps the complex Plotly API into one-liners.

📦
Install: pip install plotly. In Jupyter: charts render inline. In a script: call fig.show() which opens in your browser. Export to PNG with fig.write_image("chart.png") (needs kaleido).
Key difference from Seaborn: Plotly charts are HTML objects — every hover, zoom, and click is built-in. You do not need to write any JavaScript.
Python
import plotly.express as px
import plotly.graph_objects as go
from plotly.subplots import make_subplots

# Interactive scatter — hover shows restaurant name
fig = px.scatter(
    df.dropna(subset=["rate","cost"]).sample(3000, random_state=0),
    x="cost", y="rate", color="online_order",
    hover_data=["name","location","cuisines"],   # show on hover!
    color_discrete_map={True:"#66bb6a", False:"#ef5350"},
    labels={"cost":"₹ Cost for Two","rate":"Rating","online_order":"Online Order"},
    title="Zomato Bengaluru — Interactive Cost vs Rating",
    opacity=0.5,
)
fig.update_layout(template="plotly_white", height=500)
fig.show()   # opens interactive chart in browser

11.2 Multi-Plot Dashboard — Subplots

When & Why

A dashboard combines multiple charts into one figure. Plotly's make_subplots and Matplotlib's plt.subplots both support this. Dashboards are the primary deliverable in most industry EDA reports.

Design rule for dashboards: Top row = KPIs (numbers), Middle = distributions, Bottom = relationships/rankings. Each chart answers exactly one question. Use a consistent colour encoding across all panels.
Python
fig = make_subplots(
    rows=2, cols=3,
    subplot_titles=(
        "Rating Distribution", "Cost by Meal Type",
        "Online Order Share",
        "Top 10 Locations (Avg Rating)", "Votes vs Rating", "Cuisine Frequency"
    ),
    vertical_spacing=0.18, horizontal_spacing=0.1,
)

# 1. Rating histogram
h = df["rate"].dropna()
fig.add_trace(go.Histogram(x=h, nbinsx=25, name="Rating",

# 2. Cost box by meal type
for i, mt in enumerate(df["meal_type"].value_counts().head(4).index):

Narrative Techniques — Storytelling with Data

A chart without a story is just a picture. The best data scientists pair every visualisation with an explicit finding. Use the Situation → Complication → Resolution framework:

01

Situation

State what the chart shows. "This histogram shows restaurant rating distribution across 43,942 Bengaluru outlets."

02

Complication

Highlight the surprise or tension. "Despite 51K listings, ratings cluster above 3.8 — fewer than 4% of restaurants fall below 3.5."

03

Insight

Explain the why. "Zomato's algorithm de-ranks consistently low-rated places — survivorship bias in the data."

04

Implication

So what? "For a new restaurant, the competitive benchmark is 4.1+, not 3.0 — the market's effective floor is much higher."

"A visualisation's job is not to show the data — it is to show what the data means." — Edward Tufte, The Visual Display of Quantitative Information

Annotation — Drawing Attention

Add annotations to your charts. A horizontal line at the median, an arrow pointing to an outlier, a text box labelling a specific restaurant — these transform charts from academic to actionable.
Python
fig, ax = plt.subplots(figsize=(10, 5))

loc_avg = df.groupby("location")["rate"].mean().dropna().nlargest(15).sort_values()
bars = loc_avg.plot(kind="barh", color="#ea580c", ax=ax, alpha=0.85)

# Reference line — city average
city_avg = df["rate"].mean()
ax.axvline(city_avg, color="#333", linestyle="--", linewidth=1.2)
ax.text(city_avg + 0.01, 0.3, f"City avg\n{city_avg:.2f}",
        fontsize=8.5, color="#333")

# Annotate top bar
ax.annotate("MG Road — highest\nrated area in city",
            xy=(loc_avg.iloc[-1], len(loc_avg)-1),
            xytext=(loc_avg.iloc[-1] - 0.15, len(loc_avg)-3.5),
            fontsize=8, color=var_color := "#7c2d12",
            arrowprops=dict(arrowstyle="->", color=var_color))

ax.set(title="Top 15 Locations by Average Rating — Bengaluru",
       xlabel="Average Rating", ylabel="")
ax.set_xlim(3.5, 4.6)   # zoom into the relevant range
sns.despine(left=True)
plt.tight_layout()
plt.show()

Step 1 — Load & Prepare

Python — zomato_eda_report.py
"""
Zomato Bengaluru Intelligence Report
Module 3 — Final Project
Dataset: https://www.kaggle.com/datasets/himanshupoddar/zomato-bangalore-restaurants
"""
import pandas as pd, numpy as np, matplotlib.pyplot as plt
import seaborn as sns, plotly.express as px, warnings
from plotly.subplots import make_subplots
import plotly.graph_objects as go
warnings.filterwarnings("ignore")

sns.set_theme(style="whitegrid", palette="Set2", font_scale=1.05)
plt.rcParams.update({"figure.dpi":130,"axes.spines.top":False,"axes.spines.right":False})

# Load
df = pd.read_csv("zomato.csv", encoding="latin-1")
df.rename(columns={"approx_cost(for two people)":"cost",
                    "listed_in(type)":"meal_type",
                    "listed_in(city)":"area"}, inplace=True)

# Clean
df["rate"] = df["rate"].replace(["NEW","-"], np.nan)
df["rate"] = df["rate"].str.extract(r"(\d+\.\d+)").astype(float)
df["cost"] = df["cost"].str.replace(",","").astype(float)
df["online_order"] = df["online_order"].map({"Yes":True,"No":False})
df["book_table"]   = df["book_table"].map({"Yes":True,"No":False})

print(f"Dataset: {df.shape[0]:,} rows, {df.shape[1]} columns")

Step 2 — The 6 Investor Questions + Charts

Python
fig, axes = plt.subplots(3, 2, figsize=(14, 16))
fig.suptitle("Zomato Bengaluru — Investor Intelligence Report",
             fontsize=16, fontweight="bold", y=0.98)

# ─ Q1: How are ratings distributed? ─────────────────────────
sns.histplot(df["rate"].dropna(), bins=30, kde=True,
             color="#ea580c", ax=axes[0,0])
axes[0,0].axvline(df["rate"].mean(), color="#7c2d12", linestyle="--")
axes[0,0].set(title="Q1: Rating Distribution\n→ Market benchmark = 4.1+",
              xlabel="Rating", ylabel="Count")

# ─ Q2: Which areas have the highest rated restaurants? ───────
loc_r = df.groupby("location")["rate"].mean().dropna().nlargest(10).sort_values()
loc_r.plot(kind="barh", color="#ea580c", ax=axes[0,1])
axes[0,1].axvline(df["rate"].mean(), color="#7c2d12", linestyle="--", alpha=0.7)
axes[0,1].set(title="Q2: Top 10 Locations by Avg Rating\n→ Premium: MG Rd, Lavelle Rd",
              xlabel="Avg Rating")

# ─ Q3: Is online ordering linked to higher ratings? ──────────
sns.boxplot(data=df.dropna(subset=["rate"]), x="online_order", y="rate",
            palette={True:"#66bb6a", False:"#ef5350"}, ax=axes[1,0],
            width=0.4)
axes[1,0].set_xticklabels(["No Online Order","Online Order Available"])
axes[1,0].set(title="Q3: Online Order vs Rating\n→ Online restaurants: +0.14 stars avg",
              xlabel="", ylabel="Rating")

# ─ Q4: What is the cost landscape? ──────────────────────────
top_types = df["meal_type"].value_counts().head(5).index
order = df[df["meal_type"].isin(top_types)].groupby("meal_type")["cost"]\
           .median().sort_values().index
sns.boxplot(data=df[df["meal_type"].isin(top_types)],
            x="meal_type", y="cost", order=order,
            palette="Set2", showfliers=False, ax=axes[1,1])
axes[1,1].set(title="Q4: Cost by Meal Type\n→ Pubs 2× more expensive than Delivery",
              xlabel="", ylabel="₹ Cost for Two")
axes[1,1].tick_params(axis="x", rotation=30)

# ─ Q5: What cuisines dominate? ───────────────────────────────
cus = (df["cuisines"].dropna().str.split(", ").explode()
         .value_counts().head(10).sort_values())
cus.plot(kind="barh", color="#d97706", ax=axes[2,0])
axes[2,0].set(title="Q5: Top 10 Cuisines in Bengaluru\n→ North Indian #1, South Indian #2",
              xlabel="Number of Restaurants")

# ─ Q6: Do votes (popularity) predict rating? ─────────────────
sample = df.dropna(subset=["rate","votes"]).sample(3000, random_state=42)
axes[2,1].scatter(sample["votes"], sample["rate"],
                  alpha=0.2, s=8, color="#1e3a5f")
z = np.polyfit(sample["votes"], sample["rate"], 1)
p = np.poly1d(z)
xline = np.linspace(0, 5000, 100)
axes[2,1].plot(xline, p(xline), "r--", linewidth=1.5)
axes[2,1].set(title="Q6: Votes vs Rating (r=0.52)\n→ Popular ≈ Well-rated (but not always)",
              xlabel="Number of Votes", ylabel="Rating", xlim=(0,5000))

plt.tight_layout(rect=[0,0,1,0.97])
plt.savefig("zomato_investor_report.png", dpi=150, bbox_inches="tight")
plt.show()
print("✓ Report saved: zomato_investor_report.png")

Step 3 — Interactive Dashboard (Plotly)

Python
fig = make_subplots(
    rows=2, cols=3,
    specs=[[{"type":"histogram"},{"type":"box"},{"type":"pie"}],
           [{"type":"bar"},{"type":"scatter"},{"type":"bar"}]],
    subplot_titles=("Rating Dist","Cost by Type","Online Share",
                    "Top Areas","Votes vs Rating","Top Cuisines"),
    vertical_spacing=0.2,
)

# Row 1
fig.add_trace(go.Histogram(x=df["rate"].dropna(), nbinsx=25,
              marker_color="#ea580c", name="Rating"), 1, 1)

for mt in df["meal_type"].value_counts().head(4).index:
    fig.add_trace(go.Box(y=df[df["meal_type"]==mt]["cost"].dropna(),
                         name=mt, boxpoints=False), 1, 2)

oc = df["online_order"].value_counts()
fig.add_trace(go.Pie(labels=["Online","Offline"], values=oc.values,
              hole=0.45, marker_colors=["#66bb6a","#ef5350"]), 1, 3)

# Row 2
loc_r = df.groupby("location")["rate"].mean().dropna().nlargest(10).sort_values()
fig.add_trace(go.Bar(x=loc_r.values, y=loc_r.index,
              orientation="h", marker_color="#ea580c"), 2, 1)

s = df.dropna(subset=["rate","votes"]).sample(2000, random_state=0)
fig.add_trace(go.Scatter(x=s["votes"], y=s["rate"], mode="markers",
              marker=dict(color="#1e3a5f", opacity=0.25, size=4),
              text=s["name"], hoverinfo="text+x+y"), 2, 2)

cus = (df["cuisines"].dropna().str.split(", ").explode()
         .value_counts().head(8).sort_values())
fig.add_trace(go.Bar(x=cus.values, y=cus.index, orientation="h",
              marker_color="#d97706"), 2, 3)

fig.update_layout(height=680, showlegend=False, template="plotly_white",
                  title_text="🍽 Zomato Bengaluru — Interactive Investor Dashboard")
fig.write_html("zomato_dashboard.html")   # save as interactive HTML
fig.show()
print("✓ Interactive dashboard saved: zomato_dashboard.html")
