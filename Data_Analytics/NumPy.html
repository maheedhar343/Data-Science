What is NumPy & Why Use It?

Arjun already knows Python lists. But when he tried to add 10,000 cricket scores together using a loop — it was very slow. NumPy solves exactly this problem.

💡 The Core Idea
NumPy (Numerical Python) gives you a powerful data structure called an ndarray (N-dimensional array). It's like a Python list, but 50x faster for math, and it can handle 1D, 2D, or even 10D data. Every library in Data Science (Pandas, Scikit-learn, TensorFlow) is built on top of NumPy.
🐢 Python List
Flexible, holds mixed types, but slow for math. Uses a loop to add numbers.
⚡ NumPy Array
Fixed type, uses C under the hood, vectorized math. No loops needed.
📐 1D Array
Like a single column of a spreadsheet. E.g., list of today's Nifty prices.
📊 2D Array
Like a table (rows × columns). E.g., 11 batsmen × 5 match scores.

Creating Arrays — Many Ways

Most Used

NumPy gives you many ways to create arrays. Arjun first converts his Python lists, then learns the smarter creation functions.

🏏 IPL Context
Creating 1D & 2D arrays from Python lists
import numpy as np

# Virat Kohli's last 6 IPL match scores
scores = np.array([72, 45, 88, 30, 61, 94])
print(scores) # [72 45 88 30 61 94]
print(scores.dtype) # int64 ← NumPy picked integer type automatically

# 3 players × 4 matches (2D array — like a scorecard table)
scorecard = np.array([
    [72, 45, 88, 30], # Kohli
    [50, 62, 38, 77], # Rohit
    [90, 15, 55, 43] # Dhoni
])
print(scorecard.shape) # (3, 4) → 3 rows, 4 columns
Smart Creation Functions

You don't always start with data. Sometimes you need to create empty structures to fill in later.

np.zeros, np.ones, np.arange, np.linspace
# np.zeros — placeholder for UPI transactions (to fill later)
transactions = np.zeros(7) # 7 days of week
# → [0. 0. 0. 0. 0. 0. 0.]

# np.ones — all students scored full marks in attendance (1 = present)
attendance = np.ones((30, 5)) # 30 students, 5 days

# np.arange — like Python range(), but returns an array
overs = np.arange(1, 21) # Over 1 to Over 20 in T20
# → [ 1 2 3 4 5 ... 20]

# np.linspace — 5 evenly spaced prices between ₹100 and ₹500
price_range = np.linspace(100, 500, 5)
# → [100. 200. 300. 400. 500.]

# np.eye — identity matrix (used in linear algebra, ML)
identity = np.eye(3)
# → [[1. 0. 0.] [0. 1. 0.] [0. 0. 1.]]

Indexing & Slicing — Getting Your Data

Must Know

Just like Python lists, you can pick specific values from a NumPy array. But NumPy also supports boolean indexing — a superpower for filtering data.

💹 Nifty 50 Context
1D indexing, slicing, and boolean filtering
import numpy as np

# Nifty 50 closing prices for last 7 trading days (in ₹)
nifty = np.array([22100, 22350, 21980, 22540, 22400, 22750, 22620])

# Basic indexing — same as Python lists
print(nifty[0]) # 22100 — first day
print(nifty[-1]) # 22620 — last day

# Slicing — get middle 3 days
print(nifty[2:5]) # [21980 22540 22400]

# Boolean Indexing — find days when market went above 22500
bull_days = nifty > 22500
print(bull_days) # [F F F T F T T]
print(nifty[bull_days]) # [22540 22750 22620] ← only high days!

# Fancy Indexing — pick specific days by index list
print(nifty[[0, 3, 6]]) # [22100 22540 22620]
2D Indexing — Reading a Table
2D array — Zomato ratings across cities & categories
# Rows: Cities (Delhi, Mumbai, Bengaluru)
# Cols: Food categories (Biryani, Pizza, Dosa, Burger)
ratings = np.array([
    [4.5, 4.1, 3.8, 4.2], # Delhi
    [4.3, 4.6, 4.0, 4.4], # Mumbai
    [4.1, 3.9, 4.8, 4.0] # Bengaluru
])

# Get Bengaluru's Dosa rating [row 2, col 2]
print(ratings[2, 2]) # 4.8

# Get ALL cities' Biryani ratings (entire column 0)
print(ratings[:, 0]) # [4.5 4.3 4.1]

# Get Mumbai's all category ratings (entire row 1)
print(ratings[1, :]) # [4.3 4.6 4.0 4.4]

Mathematical Operations — The Power of Vectorization

Core Feature

This is where NumPy really shines. In Python, adding 10 to each item in a list requires a loop. In NumPy, you just write arr + 10 and it applies to all elements instantly. This is called vectorization.

⚡ Why It Matters
A for-loop on 1 million items in Python: ~200ms. Same operation in NumPy: ~2ms. That's 100× faster. Real datasets have millions of rows — this difference is critical.
🛒 E-Commerce — Meesho/Flipkart Scenario
Arithmetic operations on arrays — no loops needed
import numpy as np

# Original prices (₹) of 5 products on Flipkart
prices = np.array([1200, 850, 3400, 999, 2100])

# Apply 18% GST to all products at once
gst = prices * 0.18
# → [216. 153. 612. 179.82 378. ]

# Final price including GST
final_prices = prices + gst
print(final_prices) # → [1416. 1003. 4012. 1178.82 2478.]

# Apply Big Billion Day discount — 30% off
discounted = final_prices * (1 - 0.30)
print(discounted.round(2)) # → [ 991.2 702.1 2808.4 825.2 1734.6]

# Element-wise operations between two arrays
cost_price = np.array([800, 600, 2500, 700, 1500])
profit = prices - cost_price
profit_pct = (profit / cost_price) * 100
print(profit_pct.round(1)) # → [50. 41.7 36. 42.7 40. ] ← profit % per product
Universal Functions (ufuncs)

NumPy has built-in math functions that work directly on arrays — no loops, no imports.

np.sqrt, np.log, np.exp, np.abs
# Daily returns of a stock — some negative (loss days)
returns = np.array([2.5, -1.2, 3.1, -0.8, 1.9]) # % change

print(np.abs(returns)) # [2.5 1.2 3.1 0.8 1.9] — magnitude only
print(np.sqrt(np.abs(returns))) # square roots
print(np.log(np.abs(returns))) # log — used in finance formulas

Statistics — Summarising Your Data

Arjun gets a dataset of monthly temperatures across Indian cities. Before plotting anything, he needs to summarise the data — mean, median, standard deviation. NumPy makes this one-line operations.

🌡️ Weather Data — IMD (India Meteorological Dept)
Core statistical functions
import numpy as np

# Max temperature (°C) in Delhi for 12 months
delhi_temp = np.array([20, 23, 29, 36, 41, 40, 36, 35, 33, 29, 23, 18])

print("Mean :", np.mean(delhi_temp)) # 30.25 — average yearly temp
print("Median :", np.median(delhi_temp)) # 31.0 — middle value
print("Std Dev:", np.std(delhi_temp)) # 7.5 — how much it varies
print("Min :", np.min(delhi_temp)) # 18 — coldest month
print("Max :", np.max(delhi_temp)) # 41 — hottest month (May)
print("Sum :", np.sum(delhi_temp)) # 363
print("ArgMax :", np.argmax(delhi_temp)) # 4 — index of hottest month (May)
Axis-based Statistics on 2D Arrays
Mean along rows vs columns — city × month temperature grid
# 3 cities × 4 months (Jan, Apr, Jul, Oct)
temps = np.array([
    [18, 36, 35, 29], # Delhi
    [28, 33, 30, 32], # Mumbai
    [20, 30, 25, 26] # Bengaluru
])

# axis=1 → mean across months FOR EACH city
print(np.mean(temps, axis=1)) # → [29.5 30.75 25.25] — avg temp of each city

# axis=0 → mean across cities FOR EACH month
print(np.mean(temps, axis=0)) # → [22. 33. 30. 29.] — India avg per month
Understanding axis
axis=0 → collapses rows (you get one value per column)
axis=1 → collapses columns (you get one value per row)

Think: axis=0 goes down ↓, axis=1 goes across →

Reshape & Stacking — Organising Your Data

Real data rarely arrives in the shape you need. Arjun gets sales data as a flat list but needs it as a table. reshape() handles this, and stacking lets you combine datasets.

📦 D-Mart / Retail Sales Data
reshape, flatten, stack operations
import numpy as np

# 12 months of sales (flat list)
monthly_sales = np.arange(1, 13) * 50000 # ₹50k to ₹600k
print(monthly_sales.shape) # (12,)

# Reshape into 4 quarters × 3 months
quarterly = monthly_sales.reshape(4, 3)
print(quarterly)
# [[ 50000 100000 150000] ← Q1
# [200000 250000 300000] ← Q2
# [350000 400000 450000] ← Q3
# [500000 550000 600000]] ← Q4

# -1 means "figure out this dimension automatically"
as_2rows = monthly_sales.reshape(2, -1) # → (2, 6)

# Flatten back to 1D
flat_again = quarterly.flatten()

# Stack two store's data vertically (vstack)
store_a = np.array([100, 200, 150])
store_b = np.array([130, 180, 170])
combined = np.vstack([store_a, store_b])
# → [[100 200 150]
# [130 180 170]]

# Stack horizontally (hstack) — add a new feature column
targets = np.array([[120], [160]])
with_targets = np.hstack([combined, targets])
# → [[100 200 150 120]
# [130 180 170 160]]

Random — Generating Test Data

You can't always wait for real data. NumPy's random module lets you generate realistic fake data to test your analysis. This is used constantly in Data Science and Machine Learning.

🎯 UPSC / Exam Scores Simulation
Random number generation
import numpy as np

# Seed for reproducibility — same seed = same random numbers
np.random.seed(42) # Use any number; 42 is tradition 😄

# Simulate GATE exam scores for 500 students
# Normal distribution: mean=55, std=15 (realistic bell curve)
gate_scores = np.random.normal(loc=55, scale=15, size=500)
gate_scores = gate_scores.clip(0, 100) # No scores below 0 or above 100
print(f"Average: {gate_scores.mean():.1f}") # ≈ 55

# Random integers — simulate dice rolls (game simulation)
dice = np.random.randint(1, 7, size=10) # 10 rolls of a 6-sided die
print(dice) # e.g., [3 1 4 5 2 6 3 3 1 4]

# Random uniform — simulate UPI payment amounts ₹10 to ₹5000
payments = np.random.uniform(10, 5000, size=1000)

# Shuffle — randomly order a list (e.g., for train/test split)
students = np.arange(1, 31) # 30 students
np.random.shuffle(students) # shuffles in-place

# Choice — pick 5 random students for oral exam
selected = np.random.choice(students, size=5, replace=False)
print("Selected students:", selected)

Linear Algebra — The Math Behind ML

When Arjun starts Machine Learning, every algorithm involves matrices. NumPy's linalg module provides matrix operations that power everything from linear regression to neural networks.

🧠 Why You Need This
Linear Regression, Neural Networks, PCA, SVD — all of them are essentially matrix operations. Understanding this in NumPy first makes Scikit-learn and TensorFlow much easier later.
🏠 House Price Prediction (Simple)
Matrix multiplication and solving linear equations
import numpy as np

# Matrix multiplication — @ operator (Python 3.5+)
# Feature matrix: [area, rooms] for 3 houses in Gurugram
X = np.array([
    [1200, 3], # 1200 sqft, 3 BHK
    [800, 2], # 800 sqft, 2 BHK
    [1500, 4] # 1500 sqft, 4 BHK
])

# Weights (coefficients): ₹3000/sqft + ₹500000/room
weights = np.array([3000, 500000])

# Predicted price = X @ weights (matrix multiply)
predicted_price = X @ weights
print(predicted_price)
# [5100000 3400000 5500000] → ₹51L, ₹34L, ₹55L

# Transpose — flip rows and columns
print(X.T) # (2, 3) instead of (3, 2)

# Determinant (used to check if matrix is invertible)
A = np.array([[2, 1], [5, 3]])
print(np.linalg.det(A)) # 1.0

# Inverse of a matrix
print(np.linalg.inv(A))
# [[ 3. -1.]
# [-5. 2.]]

Putting It All Together — A Real Mini Project

🇮🇳 Full Indian Example

Arjun's college project: Analyse IPL 2024 batting performance for 5 players across 10 matches. He uses everything he learned — arrays, indexing, statistics, boolean filtering.

Complete mini-project — IPL batting analysis
import numpy as np

# ── Data Setup ──────────────────────────────────────
np.random.seed(7)
players = ['Kohli', 'Rohit', 'Gill', 'Pant', 'Iyer']

# 5 players × 10 matches — random scores (0 to 95)
scores = np.random.randint(0, 96, size=(5, 10))

# ── Analysis ────────────────────────────────────────
# Total runs per player
total_runs = np.sum(scores, axis=1)

# Average score per player
averages = np.mean(scores, axis=1)

# Strike rate proxy: times scored 50+ out of 10 matches
fifties = np.sum(scores >= 50, axis=1)

# Best match score per player
best_score = np.max(scores, axis=1)

# ── Find Best Performer ──────────────────────────────
best_idx = np.argmax(averages)
print(f"\n🏆 Best Performer: {players[best_idx]}")
print(f" Average: {averages[best_idx]:.1f}")
print(f" 50+ scores: {fifties[best_idx]}/10 matches")

# ── Consistency (low std dev = consistent) ───────────
consistency = np.std(scores, axis=1)
most_consistent_idx = np.argmin(consistency)
print(f"\n📊 Most Consistent: {players[most_consistent_idx]}")
print(f" Std Dev: {consistency[most_consistent_idx]:.1f}")

# ── Print Summary ────────────────────────────────────
print("\n--- Season Summary ---")
for i, name in enumerate(players):
    print(f"{name:8} | Runs:{total_runs[i]:4d} | Avg:{averages[i]:5.1f} | Best:{best_score[i]:3d}")
