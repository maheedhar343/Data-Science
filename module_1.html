1.1 Variables & Data Types

What is a Variable?

A variable is a named container that stores data in memory. Python is dynamically typed — you do not declare a type; Python infers it automatically from the value you assign.

Python
# Basic variable assignment
name    = "Priya"          # str  — text
age     = 25               # int  — whole number
gpa     = 8.7              # float — decimal
is_pass = True             # bool — True or False
nothing = None             # NoneType — absence of value

# Check the type
print(type(name))          # 
print(type(age))           # 
print(type(gpa))           # 

# Type conversion (casting)
age_str = str(age)         # 25 → "25"
gpa_int = int(gpa)         # 8.7 → 8  (truncates, does NOT round)
marks   = float("96.5")    # "96.5" → 96.5

1.2 Control Flow

Conditionals — if / elif / else

Python uses indentation (4 spaces) to define code blocks — there are no curly braces. Every colon at the end of a statement opens a new indented block.

Python
marks = 72

if marks >= 90:
    grade = "A+"
elif marks >= 80:
    grade = "A"
elif marks >= 70:
    grade = "B"
elif marks >= 60:
    grade = "C"
else:
    grade = "Fail"

print(f"Grade: {grade}")    # Grade: B

# One-liner conditional (ternary)
result = "Pass" if marks >= 50 else "Fail"
print(result)               # Pass

Loops — for & while

Python
# ── for loop ──────────────────────────────────────
fruits = ["apple", "banana", "mango"]

for fruit in fruits:
    print(fruit.upper())
# APPLE  BANANA  MANGO

# range(start, stop, step)
for i in range(1, 6):
    print(i, end=" ")       # 1 2 3 4 5

# enumerate — get index + value together
for idx, fruit in enumerate(fruits, start=1):
    print(f"{idx}. {fruit}")
# 1. apple   2. banana   3. mango

# ── while loop ────────────────────────────────────
count = 0
while count < 3:
    print(f"Count is {count}")
    count += 1              # ALWAYS increment to avoid infinite loop

# ── Loop control ──────────────────────────────────
for n in range(1, 11):
    if n == 4: continue     # skip 4
    if n == 8: break        # stop at 8
    print(n, end=" ")       # 1 2 3 5 6 7
💡
Tip — Prefer for over while Use for loops whenever you know the number of iterations or are iterating over a collection. Reserve while for cases where the stop condition is dynamic (e.g., waiting for user input, convergence checks).
1.3 Functions

Defining and Calling Functions

Functions let you reuse code and keep your programs readable. In data science, well-named functions make your analysis pipelines self-documenting.

Python
# Basic function
def greet(name):
    return f"Hello, {name}!"

print(greet("Rahul"))       # Hello, Rahul!

# Default parameters
def power(base, exp=2):
    return base ** exp

print(power(3))             # 9   (uses default exp=2)
print(power(3, 3))          # 27

# Multiple return values (returned as tuple)
def stats(numbers):
    total   = sum(numbers)
    average = total / len(numbers)
    return total, average

t, avg = stats([10, 20, 30, 40])
print(f"Total: {t}, Average: {avg}")   # Total: 100, Average: 25.0

# *args — variable number of positional arguments
def add_all(*args):
    return sum(args)

print(add_all(1, 2, 3, 4, 5))   # 15

# **kwargs — variable keyword arguments
def student_info(**kwargs):
    for key, value in kwargs.items():
        print(f"  {key}: {value}")

student_info(name="Aisha", age=22, city="Kochi")

Set — Unique Unordered Items

Automatically removes duplicates. Supports fast membership testing and mathematical set operations (union, intersection, difference).

# Fast membership test — O(1) vs O(n) for list
big_set  = set(range(1_000_000))
print(999_999 in big_set)    # True — instant

Comprehensions

Comprehensions are Pythonic one-liners that build lists, sets, and dictionaries concisely. They replace many for loops with cleaner, faster code — a staple in data science scripts.

Python
numbers = range(1, 11)       # 1 to 10

# ── List Comprehension  [expression  for item in iterable  if condition] ──
squares    = [x**2 for x in numbers]
# [1, 4, 9, 16, 25, 36, 49, 64, 81, 100]

even_sq    = [x**2 for x in numbers if x % 2 == 0]
# [4, 16, 36, 64, 100]

# Cleaning text — real-world use
raw = ["  Alice ", "BOB", "", "carol  "]
clean = [name.strip().title() for name in raw if name.strip()]
# ['Alice', 'Bob', 'Carol']

# ── Dict Comprehension  {key: value  for item in iterable} ──
word_lengths = {word: len(word) for word in ["python","pandas","numpy"]}
# {'python': 6, 'pandas': 6, 'numpy': 5}

# ── Set Comprehension ──
unique_lengths = {len(word) for word in ["cat","dog","elephant","ant"]}
# {3, 8}  (unique lengths only)
⭐
When to use Comprehensions vs regular loops Use comprehensions when building a new collection from an existing one with a clear one-step transformation. Use regular for loops when the body is complex (multiple statements, nested conditions, side effects). Readability always wins.

2.1 Classes & Objects

Defining a Class

A class is a blueprint. An object is a specific instance built from that blueprint. The __init__ method is the constructor — it runs automatically when you create a new object.

Python
class Student:
    # Class attribute — shared by ALL instances
    institution = "Data Science Institute"

    # __init__ is the constructor; 'self' refers to the instance
    def __init__(self, name, age, marks):
        # Instance attributes — unique to each object
        self.name  = name
        self.age   = age
        self.marks = marks

    # Instance method
    def grade(self):
        if self.marks >= 90:
            return "A+"
        elif self.marks >= 75:
            return "A"
        else:
            return "B"

    # Special method — controls print() output
    def __repr__(self):
        return f"Student(name='{self.name}', marks={self.marks})"


# ── Creating objects (instances) ──
s1 = Student("Priya",  21, 92)
s2 = Student("Arjun",  23, 78)

print(s1.grade())                # A+
print(s2.grade())                # A
print(s1.institution)            # Data Science Institute
print(s2)                        # Student(name='Arjun', marks=78)
2.2 Inheritance

Extending Classes

Inheritance lets a child class reuse and extend the behaviour of a parent class. This is exactly how Sklearn builds DecisionTreeClassifier on top of a generic BaseEstimator.

Python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age  = age

    def introduce(self):
        return f"Hi, I'm {self.name}, age {self.age}."


class DataScientist(Person):           # inherits from Person
    def __init__(self, name, age, specialty):
        super().__init__(name, age)    # call parent constructor
        self.specialty = specialty

    # Override parent method
    def introduce(self):
        base = super().introduce()
        return f"{base} I specialise in {self.specialty}."

    def fit(self, data):
        return f"{self.name} is fitting a model on {len(data)} rows."


ds = DataScientist("Neha", 28, "NLP")
print(ds.introduce())
# Hi, I'm Neha, age 28. I specialise in NLP.

print(ds.fit([1, 2, 3, 4, 5]))
# Neha is fitting a model on 5 rows.
2.3 Encapsulation

Protecting Data

Encapsulation hides internal details and exposes only what is necessary. In Python, a single underscore _attr signals "internal use" and a double underscore __attr triggers name-mangling for stronger protection.

Python
class BankAccount:
    def __init__(self, owner, balance):
        self.owner    = owner
        self.__balance = balance      # private — cannot access directly

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount

    def withdraw(self, amount):
        if 0 < amount <= self.__balance:
            self.__balance -= amount
            return amount
        raise ValueError("Insufficient funds")

    # Getter — controlled read access
    @property
    def balance(self):
        return round(self.__balance, 2)


acc = BankAccount("Rohit", 5000)
acc.deposit(1000)
print(acc.balance)          # 6000

# acc.__balance              # ❌ AttributeError
# But you CAN access via:   acc._BankAccount__balance  (avoid this)

3.1 NumPy — Numerical Computing

Why NumPy?

A Python list is slow for numerical operations — each element is a Python object with overhead. NumPy stores data in a contiguous block of typed memory, enabling vectorized operations that are 50–100× faster without any loops.

Python
import numpy as np

# ── Creating arrays ───────────────────────────────
a = np.array([1, 2, 3, 4, 5])
print(a.dtype)          # int64
print(a.shape)          # (5,)

# Useful constructors
zeros  = np.zeros((3, 4))       # 3×4 matrix of 0.0
ones   = np.ones((2, 3))        # 2×3 matrix of 1.0
rng    = np.arange(0, 20, 2)    # [0, 2, 4, 6, ... 18]
linsp  = np.linspace(0, 1, 5)   # [0.0, 0.25, 0.5, 0.75, 1.0]
rand   = np.random.seed(42); np.random.rand(3, 3)  # random 3×3

# ── Vectorized Operations (NO loops needed!) ──────
prices  = np.array([100, 200, 150, 300, 250])
tax_rate = 0.18

# Applies to every element simultaneously
prices_with_tax = prices * (1 + tax_rate)
print(prices_with_tax)   # [118. 236. 177. 354. 295.]

discount_mask = prices > 200
print(prices[discount_mask])  # [300 250]  — boolean indexing

4.1 Missing Values

Detecting Missing Data

Python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    "name"  : ["Alice", "Bob",  "Carol", "David", "Eve"],
    "age"   : [24,      np.nan, 27,      np.nan,  35],
    "salary": [55000,   80000,  np.nan,  48000,   92000],
    "city"  : ["Mumbai","Delhi",np.nan,  "Pune",   "Delhi"],
})

# Detection
print(df.isnull())              # boolean mask
print(df.isnull().sum())        # missing count per column
print(df.isnull().sum() / len(df) * 100)  # missing % per column

# age      2  → 40%
# salary   1  → 20%
# city     1  → 20%

Strategies for Handling Missing Data

1

Drop — when missingness is >50% or random

Remove entire rows or columns when data is too sparse to be useful.

2

Fill with statistic — numerical columns

Use mean (normally distributed data) or median (skewed data / outliers present).

3

Fill with mode / constant — categorical columns

Use the most frequent value or a meaningful placeholder like "Unknown".

4

Forward/Backward fill — time-series data

Propagate the last valid value forward or the next valid value backward.

Python
# ── Drop ──────────────────────────────────────────
df.dropna(inplace=True)                   # drop any row with NaN
df.dropna(subset=["salary"], inplace=True)# drop only if salary is NaN
df.dropna(thresh=3, inplace=True)         # keep rows with ≥3 non-NaN

# ── Fill — Numerical ──────────────────────────────
mean_age   = df["age"].mean()
median_sal = df["salary"].median()

df["age"]   .fillna(mean_age,    inplace=True)
df["salary"].fillna(median_sal,  inplace=True)

# ── Fill — Categorical ────────────────────────────
mode_city = df["city"].mode()[0]
df["city"].fillna(mode_city, inplace=True)
df["city"].fillna("Unknown", inplace=True)  # or constant

# ── Forward / Backward fill (time-series) ─────────
df["price"].fillna(method="ffill", inplace=True)  # forward fill
df["price"].fillna(method="bfill", inplace=True)  # backward fill

# ── Interpolation ─────────────────────────────────
df["temperature"] = df["temperature"].interpolate(method="linear")

4.3 Outlier Detection & Treatment

IQR Method (Robust — Recommended)

The Inter-Quartile Range method is robust to extreme values and works well for most real-world datasets without assuming any distribution.

Python
import numpy as np

salary = df["salary"]

Q1  = salary.quantile(0.25)     # 25th percentile
Q3  = salary.quantile(0.75)     # 75th percentile
IQR = Q3 - Q1

lower_fence = Q1 - 1.5 * IQR
upper_fence = Q3 + 1.5 * IQR

# Detect outliers
outliers = df[(salary < lower_fence) | (salary > upper_fence)]
print(f"Outliers found: {len(outliers)}")

# Treatment Options:
# 1. Remove outliers
df_clean = df[(salary >= lower_fence) & (salary <= upper_fence)]

# 2. Cap / Winsorize (best for ML — preserves row count)
df["salary_capped"] = salary.clip(lower=lower_fence, upper=upper_fence)

Z-Score Method (Normal Distributions)

Python
from scipy import stats

z_scores = np.abs(stats.zscore(df["salary"]))
# Threshold of 3 → values more than 3 std deviations from mean
outlier_mask = z_scores > 3
df_clean = df[~outlier_mask]
print(f"Removed {outlier_mask.sum()} outliers")

5.2 REST APIs with the Requests Library

What is a REST API?

An API (Application Programming Interface) is a gateway to retrieve live data from web services. As a data scientist, you'll fetch weather data, financial data, social media feeds, and more through REST APIs using HTTP methods.

📥

GET

Retrieve data from a server. Used 90% of the time in data science to fetch datasets.

📤

POST

Send data to a server (e.g., submit a form, call an ML model endpoint).

🔑

Headers

Metadata sent with every request — most commonly an Authorization/API key.

📊

Status Codes

200 OK, 201 Created, 400 Bad Request, 401 Unauthorized, 404 Not Found, 500 Server Error.

Python
import requests

Error Handling & Best Practices

Python
import requests
import time

def fetch_with_retry(url, max_retries=3, delay=2):
    """Robust API call with retry logic."""
    for attempt in range(max_retries):
        try:
            response = requests.get(url, timeout=10)
            response.raise_for_status()   # raises exception for 4xx/5xx
            return response.json()
        except requests.exceptions.Timeout:
            print(f"Timeout. Retry {attempt+1}/{max_retries}")
            time.sleep(delay)
        except requests.exceptions.HTTPError as e:
            print(f"HTTP Error: {e}")
            break
        except requests.exceptions.ConnectionError:
            print("Network unavailable")
            break
    return None

# Paginated API — fetch multiple pages
all_results = []
for page in range(1, 6):           # pages 1 to 5
    url  = f"https://api.example.com/data?page={page}&limit=100"
    data = fetch_with_retry(url)
    if data:
        all_results.extend(data["items"])
    time.sleep(0.5)                 # be polite — respect rate limits

df = pd.DataFrame(all_results)

def clean_retail_data(df):
    """
    Complete cleaning pipeline for retail sales data.
    Returns a cleaned copy of the DataFrame.
    """
    df = df.copy()

    # 1. Remove exact duplicates
    before = len(df)
    df.drop_duplicates(inplace=True)
    print(f"Duplicates removed: {before - len(df)}")

    # 2. Fix column names (lowercase, no spaces)
    df.columns = df.columns.str.strip().str.lower().str.replace(" ", "_")

    # 3. Type conversion
    df["order_date"]  = pd.to_datetime(df["order_date"], errors="coerce")
    df["price"]       = pd.to_numeric(df["price"],       errors="coerce")
    df["quantity"]    = pd.to_numeric(df["quantity"],     errors="coerce")

    # 4. Handle missing values
    df["category"].fillna("Unknown", inplace=True)
    df["region"]  .fillna(df["region"].mode()[0], inplace=True)
    df["price"]   .fillna(df["price"].median(),   inplace=True)
    df["quantity"].fillna(1, inplace=True)

    # 5. Cap price outliers using IQR
    Q1, Q3 = df["price"].quantile([0.25, 0.75])
    IQR    = Q3 - Q1
    df["price"] = df["price"].clip(lower=Q1 - 1.5*IQR,
                                    upper=Q3 + 1.5*IQR)

    print(f"Clean dataset shape: {df.shape}")
    return df

df = clean_retail_data(df)
